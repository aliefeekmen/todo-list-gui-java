# To-Do List GUI App

This is a simple Java GUI application for managing daily tasks.

## Features
- Add tasks
- Delete tasks
- View task list in a window

## Technologies
- Java
- Java Swing
- ArrayList
- GUI Programming

## How to Run
1. Download or clone the project
2. Open the project in any Java IDE
3. Run the `TodoApp.java` file

## Purpose
This project was created to practice Java GUI development and basic task management logic.
